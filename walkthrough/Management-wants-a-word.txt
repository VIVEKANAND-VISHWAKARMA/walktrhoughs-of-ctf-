Method 2 — manual decrypt (no sudo, no mount tools)
--------------------------------------------------------
The container uses ABSOLUTE XTS data units (tweak = offset/512),
not the usual relative ones, so standard offsets give garbage.

   # header: salt[0:64] + encrypted header[64:512]
   key  = PBKDF2-HMAC-SHA512(pass, salt, 500000, dklen=64)
   hdr  = AES-XTS-decrypt(header, key)           # magic "VERA", CRC ok
   mk   = hdr[192:256]                           # volume master key

   # decrypt every sector, tweak = sector number = offset // 512
   for off in range(0, len(backup), 512):
       decrypt(XTS(mk, tweak=off//512), backup[off:off+512])

   -> dec_abs.bin  (FAT32, boot sector at offset 131072 = unit 256)

   7z l dec_abs.bin
   7z x dec_abs.bin
   -> secret_financial_documents/important_invoice_byte_lotus.pdf
